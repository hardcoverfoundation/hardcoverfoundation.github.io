# Claude Implementation Prompt — Phase 1

Use this only after the content strategy and design plan have been reviewed and
approved.

The approved priorities are:

1. Position Hardcover around expanded literacy and the ability to read life.
2. Treat the READ Framework as the central methodology.
3. Present programs as applications of the philosophy, not unrelated
   activities.
4. Keep community impact more prominent than personal or business benefits.
5. Maintain accurate nonprofit, governance, and tax-status language.
6. Do not fabricate programs, metrics, people, partners, stories, or outcomes.
7. Treat paid-source mockups only as high-level moodboards.
8. Preserve the custom domain and existing site in Git history.
9. Work only on the approved redesign branch.
10. Do not push, merge, or deploy.

## Implement only

- global design tokens
- typography system
- responsive layout primitives
- accessible header and navigation
- homepage
- expanded-literacy section
- READ Framework component
- footer
- reusable program and initiative content models
- one reusable program-detail template

Do not build every secondary page yet.

## Validation

- run the development server
- review approximately 1440px, 1024px, 768px, and 390px layouts
- check overflow, spacing, alignment, typography, focus states, and image
  cropping
- run the production build
- run available accessibility checks
- report unresolved issues
- stop for human design review
